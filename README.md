# Uth Ja! ⏰

The hardest alarm. No snooze. It keeps ringing until you solve the day's challenges.

- 3 rounds a day, picked from: 🧮 Math · 🧠 GK Quiz · 💃 Dance/Shake · 🔢 Memory
- The mix changes every day
- Max volume, enforced; back button disabled; comes back if closed
- Emergency exit: 20 math problems in a row

## Install
Every push to `main` builds the app automatically. On your phone, open
**Releases → latest → UthJa.apk**, download it and install it (allow "Install unknown apps" when asked).
